LOU Control Center

This wizard installs the application, its self-contained .NET runtime, monitoring tools and artwork. No additional downloads are required for these components.

Advanced sensor readings use the official signed PawnIO component (installed if needed) and a background collector running with system privileges. It reads temperatures, fan speeds and application presentation rates, without recording displayed content or keystrokes. It never changes fan curves.

On first launch, choose your city and assign fans and pump to the correct sensors. Compatible displays are detected automatically. Exit TRCC and any other LOU edition before opening this application.

Microsoft WinUSB is included in Windows. Displays declaring compatibility are recognized automatically. Other hardware variants may require their manufacturer's driver; unsupported models are reported in the app.

Windows startup is optional. Uninstalling removes LOU and its collector task but keeps your settings. PawnIO is shared with other applications and stays installed; remove it separately through Windows if no longer needed.

Choose English or French in Settings. Optional GitHub update checks offer downloads in your browser; no update is installed automatically.
